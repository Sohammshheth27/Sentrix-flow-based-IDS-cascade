# ET Open signature Category Priority Fires

Two-stage filter

Suricata's raw event stream is dominated by low-severity informational rule firings (TLS handshake traces, HTTP response-headers, DNS resolution logs, ICMP info events) which document protocol behaviour rather than represent attack hypotheses. The actionable subset is recovered by a two-stage filter: (1) severity filter: retain high- and medium-severity rule firings, discard low-severity informational; (2) category filter: retain attack-relevant rule classes (trojan-activity, command-and-control, exploit-attempt, attempted-user/admin access, web-application-attack, reconnaissance, policy-violation), discard informational classes. The two engines observe different evidence classes (flow-feature behaviour vs payload-pattern matching), so their false-positive surfaces are orthogonal and integration multiplies coverage without compounding noise.

Peer Groups · Behavioural cohorts

auto-detected · manually defined
Peer groups are clusters of devices that exhibit similar network behaviour (flow shape, port mix, timing) over the UEBA baseline window. A device deviating from its peer-group norm is flagged before it deviates from its own historical baseline — catches insider-threat / compromised-credential patterns the per-host UEBA misses.
